# Loadout Characters

Loadout Characters saves a separate character preference list for each loadout profile in PAYDAY 2. When you switch profiles, the mod restores that profile's character preferences along with your weapons and gear.

If another player is using your first choice, the mod checks up to four preferences in order and picks the first available character. This fallback leaves your saved preference order intact. If every preferred character is taken, you keep your current character.

## Installation

1. Install [SuperBLT](https://superblt.znix.xyz/).
2. Place the mod folder inside `PAYDAY 2/mods/`. The `mod.txt` file should be directly inside the mod folder, for example at `PAYDAY 2/mods/Character Saving/mod.txt`.
3. Restart PAYDAY 2.

## Usage

1. Select a loadout profile in your inventory.
2. Open the character menu and set the preference order for that profile.
3. Repeat for your other profiles. Switching back to a profile restores its saved preferences.

Existing profiles inherit your current preference list the first time you use them with the mod. Set up each profile you want to use with a different character.

## Multiplayer

Live character switching is designed for the lobby and the pre-heist briefing screen. Everyone in the lobby, including the host, needs the same version of the mod. If someone does not have the mod, your preferences are still saved and the game uses them the next time you join a lobby.

Once the heist intro begins, or when you join a heist already in progress, you play as the character assigned by the game.
